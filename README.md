<div align="center">
  <h2>🚀 Projects</h2>
  <p>Here are some of my significant projects:</p>
</div>

-   <h3>ResumeIQ: AI-powered Resume Analyzer and ATS Scoring Platform</h3>
    <p>An intelligent platform designed to analyze resumes, provide ATS compatibility scores, and suggest improvements. Built with <b>FastAPI</b> for the backend, <b>React</b> for a dynamic frontend, <b>PostgreSQL</b> for data persistence, and secured with <b>JWT Authentication</b>. Features include resume parsing, ATS score calculation, and job match analysis.</p>

-   <h3>AI Dataset Analysis Chatbot</h3>
    <p>A conversational AI chatbot developed using <b>Rasa</b>, integrated with <b>Machine Learning</b> models to facilitate interactive dataset analysis and visualization. It generates insightful dashboards and provides data-driven insights through natural language interaction.</p>

-   <h3>Real-Time Object Detection Mobile App</h3>
    <p>A mobile application developed using <b>Flutter</b>, capable of performing real-time object detection. It incorporates an <b>SSD (Single Shot MultiBox Detector)</b> model to identify objects, estimates their distance, and provides voice feedback for an enhanced user experience.</p>
    
-   <h3>Github Pilot: AI-powered Chrome Extension</h3>
    <p>An AI-powered Chrome extension designed to help users create more professional GitHub profiles. It leverages <b>FastAPI</b> for backend services, <b>React</b> for an interactive popup screen, <b>Machine Learning</b> algorithms, and the <b>Gemini AI</b> for intelligent content generation and suggestions.</p>
